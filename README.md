# Digit Generator App

An interactive web application that generates handwritten digit images using Machine Learning. The app allows users to experiment with generating different handwritten digit images through an intuitive interface.

## 🔗 Live Demo

[Try Digit Generator App](https://digitgeneratorrohitkhadka.streamlit.app/)

> **Note:** The app is deployed on Streamlit Cloud, which may go into sleep mode when inactive. If the app doesn't load immediately, please wait for a few moments while it starts up.

## ✨ Features

- Generate realistic handwritten digit images
- Interactive user interface
- Real-time generation
- Easy to use
- Powered by Machine Learning

## 🚀 Technologies Used

- Python
- Streamlit
- Machine Learning
- Neural Networks

## 💻 How to Use

1. Visit the [Digit Generator App](https://digitgeneratorrohitkhadka.streamlit.app/)
2. Wait for the app to load (may take a few moments if the server was in sleep mode)
3. Use the interface to generate different handwritten digits
4. Experiment with different inputs to see various results

## 🛠️ Local Development

To run this project locally:

1. Clone the repository
2. Install the required dependencies:
```bash
pip install -r requirements.txt
```
3. Run the Streamlit app:
```bash
streamlit run app.py
```
